# Journal

个人技术知识笔记，使用 TypeScript 和 VitePress 构建。

配套 Skill（Private）：[sklme/journal-skills](https://github.com/sklme/journal-skills)

## 本地预览

```bash
pnpm install
pnpm docs:dev
```

## 检查

```bash
pnpm check
```

仓库内容提交前必须完成脱敏和人工复核。

## 文章写作

先确定读者已有的知识，以及读完后应当能够解释或完成的事情，再组织正文。学习文章可以沿着问题、例子、观察和解释逐步推进；操作指南按实际任务展开；速查文章便于检索。按文章目标选择写法，不要求所有文章使用相同章节。

`templates/knowledge.md` 提供元信息格式和写作提示。文件路径、Frontmatter、脱敏、导航、内容日志和构建检查属于仓库要求；正文标题、章节顺序、篇幅和叙述方式由文章目标决定。

从对话整理文章时，保留推动理解的疑问、反例、实验和纠错，删去状态汇报和重复交流。需要展示错误理解时，把它明确标为待检验的假设，紧接着解释为什么需要修正。可以用一个逐步演进的例子串起机制，再引入术语；不必把这些内容拆成统一的“原理、示例、边界”栏目。

读者已经认可的稿件，在纳入仓库时保留其讲解顺序与深度。阅读检查关注读者能否跟上推理、解释关键区别、将结论用于相近问题；工程检查验证格式、安全和站点集成，两者分别完成。

## 导航维护

文章文件和 URL 保持稳定，主题导航由 `docs/.vitepress/navigation.mts` 统一维护。

- 新增文章后，在对应主题的专题分组中登记标题、摘要和原始链接；主题卡片、文章列表、顶部导航高亮和独立侧栏会使用同一份目录。
- 主题首页放在 `docs/knowledge/topics/<topic>/index.md`，用 `TopicArticles` 展示专题文章。它们是导航页，不增加内容日志条目。
- 内容日志保持按月份倒序、每篇文章一个原始 URL 的规则，导航调整不修改日志分类或收录时间。
- `pnpm check` 验证所有文章恰好归属一个主题、侧栏只显示当前主题、主题入口与站内锚点有效，并检查构建后的日志链接。
