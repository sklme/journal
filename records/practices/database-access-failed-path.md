# 数据库操作权限申请：失败路径记录

日期：2026-11-02  
性质：本次内部实践的脱敏记录，保存在仓库的非站点目录，不纳入知识站点。

最终决定：MCP 授权加 DMS 网页操作的路径没有走通，停止继续探索，回到最初的数据库变更网页填单。本文只记录尝试过程，不作为可复用的操作指南。

## 本来要做什么

目标是操作目标模块对应的已有业务数据库：创建测试表、修改表结构，最后删除测试表。不是新建数据库。

最初打开的是数据库变更申请页面的访问授权入口。后来希望通过 MCP 完成授权，再自己用网页客户端操作，减少手工填单和连接环境准备。

## 实际尝试路径

| 顺序 | 做了什么 | 实际结果 |
| --- | --- | --- |
| 1 | 查看原始网页的访问授权表单 | 需要填写目标库、访问来源、数据库账号及权限；没有在这一步提交 |
| 2 | 在模块管理页面申请备份开发负责人 | 已申请成功；后续任务的模块负责人快照也包含当前操作者 |
| 3 | 给现有访问令牌增加云 PaaS MCP 服务授权 | 已保存，保留原来的 4 项授权 |
| 4 | 添加本地数据库管理 MCP 服务配置，复用已有令牌 | 已完成，保留其他配置；没有在记录中保存令牌内容 |
| 5 | 做只读调用，检查连接、模块信息和可用工具 | MCP 可调用；该次工具清单中没有直接执行建表、改表、删表 SQL 的能力 |
| 6 | 考虑本机客户端、SSH 隧道和开发机 | 根据指引和运维答复，开发环境默认不通目标现网环境；放弃该候选方案，未实测开发机连接 |
| 7 | 转向 DMS 网页客户端 | 用户完成云账号登录；通过只读查询和页面搜索找到了目标实例，但尚未登录数据库 |
| 8 | 做一次经确认的登录诊断 | 登录失败，页面提示 DMS 连接数据库使用的来源 IP；这不是本机 IP，也不是数据库目标 IP |
| 9 | 按确认参数通过 MCP 提交一次授权 | 请求受理并返回审计任务；后续查询到失败终态，未进入授权执行 |
| 10 | 停止这条路径 | 回到原始数据库变更网页填单 |

过程中另有生产网络环境可用于连接的建议，但没有实践。也没有证明 MCP 授权能免除原始变更网页的审批流程。

## 最后一次授权及失败点

授权目标为所选 DB 角色对应的已有库，采用新数据库账号，来源按 IP 填写，使用 DMS 诊断提示的地址。申请权限为 `create`、`alter`、`drop`，范围是目标库，密码交由平台生成。

接口返回任务标识只表示请求被受理。随后查询任务，结果为：

- 任务阶段：`SubmitFailed`。
- 任务已完成，结果失败。
- 拒绝原因：当前操作者不是目标 DB 角色的负责人。
- 模块负责人快照已经包含当前操作者。
- 没有进入授权执行阶段。

因此，本次卡在下游 **DB 角色负责人校验**。已成为模块备份开发负责人，并没有让这次角色授权通过。两个负责人名单的关系、同步机制和具体校验规则没有继续查清，不能断言是哪一种原因。

DMS 诊断使用的是计划创建的账号及临时诊断密码；失败提示提供了来源地址，但没有证明账号存在、密码有效，也不能仅凭这个提示认定来源授权是唯一问题。

## 停止时的状态

MCP 配置和服务访问授权已保留，备份开发负责人身份已登记。此次数据库授权失败，不能声称新数据库账号已经创建或具备权限。

没有成功登录数据库，没有执行建表、改表或删表 SQL。授权失败后没有再次尝试登录或重复提交。

## 最后采用的方式

回到原始数据库变更网页，按照页面提供的变更类型和填写要求走原有填单流程。暂不继续解决 MCP 到 DB 角色的负责人校验，也不再把 DMS 直连作为本次任务的前提。

这里记录的是最终选择；截至本记录，尚没有原始网页重新填单后的提交、审批或执行成功结果。
